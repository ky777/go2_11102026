#### Коды ответов веб-сервера
##### Успешные ответы (2xx)
- 200 OK — стандартный успешный ответ для большинства запросов.
- 201 Created — запрос выполнен успешно, и в результате был создан новый ресурс (обычно после POST или PUT).
- 202 Accepted — запрос принят на обработку, но обработка ещё не завершена (для асинхронных операций).
- 204 No Content — запрос обработан успешно, но нет данных для возврата (часто используется в REST API).
##### Ошибки клиента (4xx)
- 400 Bad Request — запрос содержит некорректный синтаксис.
- 401 Unauthorized — требуется аутентификация для доступа к ресурсу.
- 403 Forbidden — доступ к ресурсу запрещён.
- 404 Not Found — запрашиваемый ресурс не найден.
- 429 Too Many Requests — превышено ограничение на количество запросов (например, из-за перегрузки).

##### Ошибки сервера (5xx)
- 500 Internal Server Error — общая внутренняя ошибка сервера.
- 502 Bad Gateway — сервер, выступая в роли шлюза или прокси, получил недопустимый ответ от другого сервера.
- 503 Service Unavailable — сервер временно не может обработать запрос (из-за перегрузки или технического обслуживания).
- 504 Gateway Timeout — сервер не смог получить ответ от другого сервера в установленное время.

1. Создание модуля в корне проекта
```
go mod init <git_server>/<account_name>/<repo_name>
```
После отработки команды будет создан файл: `go.mod`


2. Создание в корне рабочего пространства(workspace)
```
go work init
```
После отработки команды будет создан файл: `go.work`

3. Для добавления каталога, в котором расположен отдельный модуль, в рабочее пространство
```
go work use ./Lection1_JSON/
```
4. Для добавления теста, нужно добавить файл с постфиксом \_test и  метод с именем с префиксом test\_ или постфиксом \_test. 
Запуск теста:
```
go test .
go test -v . //выводит более подробный результат.
```
