# go2_08122025

1. Создание модуля в корне проекта
```
go mod init <git_server>/<account_name>/<repo_name>
```
После отработки команды будет создан файл: `go.mod`


2. Создание в корне рабочего пространства(workspace)
```
go work init
```
После отработки команды будет создан файл: `go.work`

3. Для добавления каталога, в котором расположен отдельный модуль, в рабочее пространство
```
go work use ./Lection1_JSON/
```
